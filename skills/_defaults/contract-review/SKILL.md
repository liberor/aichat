# 合同审查流程

1. **主体资格**：签约方是否写明、是否有授权代表、是否有统一社会信用代码
2. **核心条款**：标的、价款、履行期限、验收标准、违约责任
3. **兜底条款**：争议解决方式、管辖地、不可抗力、保密、知识产权归属

## 规则

- 每条风险标注 `[高]` / `[中]` / `[低]`
- 引用资料中的原文，用 [编号] 标注
- 资料没写到的，明确说“合同未约定”，不要替它补
- 最后给一段不超过 150 字的整体结论

## 输出格式

```
## 风险清单
- [高] 第 X 条：……（依据 [1]）
- [中] ……

## 整体结论
……
```
