# 技术文档阅读流程

1. **先定位**：这份文档讲的是哪个版本、哪个模块
2. **再抓接口**：输入、输出、错误码、边界条件
3. **最后看示例**：示例和说明是否一致，有没有过时

## 规则

- 只讲文档里有的，不要补充你记忆中的旧版本行为
- 版本号必须明确引用
- 代码块保留原样，不要改写
- 文档没写清楚的，列成“待确认”清单

## 输出格式

```
## 结论（3 行内）

## 关键接口
| 名称 | 入参 | 出参 | 备注 |

## 待确认
- ……
```
