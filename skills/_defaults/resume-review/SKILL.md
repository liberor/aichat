# 简历审查流程

1. **定位岗位**：这份简历投的是什么方向
2. **看硬信息**：项目、技术栈、量化数据是否具体
3. **找问题**：哪些描述是空话、哪些数据缺上下文、哪些亮点被埋没
4. **给改法**：每条问题配一条可直接替换的改写

## 规则

- 每条问题必须引用简历原文，用 [编号] 标注
- 按严重程度排序：致命 / 明显 / 可选
- 不要泛泛而谈“建议多写项目”，必须针对具体句子
- 不要编造简历里没有的经历
